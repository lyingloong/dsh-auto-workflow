# dsh-auto-workflow v1.1.0

这是 `dsh-auto-workflow` 的 feature release，重点是开发示例的 PR 交流规范与仓库初始化。

## 新增

- PR body 状态块：`task`、`head`、`base`、`stage`、`next`、`order`、`ci`。
- 角色头：`[role=reviewer] [task=...] [head=...]`。
- 顶层评论约定：`[verify]`、`[review]`、`[repair]`、`[merge-gate]`。
- finding/thread 规则：未 resolve 的 thread 阻止 merge-ready；新 head 使旧结论失效。
- `workflow:merge-ready` 标签：只有 head 匹配、CI 通过或无 CI、review thread 全 resolve 时才添加。
- `pr-init`：创建 workflow 前检查仓库；默认只读，`apply` 只创建标签和缺失的 PR template。
- PR 模式同时支持外部直接 merge，以及宽限期后 Human 批准的自 merge。

## 升级

1. 安装 v1.1.0。
2. 在创建/启动 workflow 前运行：

```bash
$env:DSH_WORKFLOW_INPUT = '{"repoRoot":"C:/work/project","baseBranch":"integration/workflow-batch"}'
node docs/examples/development/driver.mjs pr-init
```

3. 按检查结果手动配置 branch protection / merge method；`pr-init` 不会自动修改这些仓库设置。
4. 已存在的 PR 需要补齐状态块和 merge-ready 标签，才能进入新的合并门。
