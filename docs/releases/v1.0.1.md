# dsh-auto-workflow v1.0.1

这是 `dsh-auto-workflow` 的补丁发布，主要更新唯一主示例的自动开发流：

- 每需求一个 `auto/req-*` 分支和 attached worktree；
- snapshot 把需求分支压成单 commit；
- 第一次 snapshot 后 push 分支并创建自己的 draft PR；
- review pass + brief 后 PR 标记 ready，外部 Codex/人可以直接 merge，不需要内部 Human 先批准；
- 如果 `selfMergeAfterMs` 宽限期后仍未 merge，才进入 `self-merge-human`；Human 同意后工作流用 merge commit 合并自己的 PR；
- Human 详情默认显示结构化 brief（需求、改动、验证、审查、风险），原始输入折叠；同一 brief 作为 PR body；
- 看板节点队列改为可滚动的彩色方块网格，节点图保留简化模式；
- merge 冲突自动 abort 的行为仍保留在 local fallback。

## 升级注意

- 旧的 detached worktree 数据**不迁移、不重放**；请使用新的 canonical `dataRoot`。
- pull-request 模式需要 GitHub remote、`gh` 登录或 `GITHUB_TOKEN`，并需要 `Contents: Write` 与 `Pull requests: Write`。
- 外部 merge 和 workflow self-merge 都要求 **merge commit**；squash/rebase 会改变 commit SHA，工作流会拒绝。
- 旧 v1.0.0 的 tag/Release 保留，不移动。

## 安装

```bash
dsh plugin --profile desktop add github:lyingloong/dsh-auto-workflow#v1.0.1
```

也可下载本 Release 的 `dsh-auto-workflow-1.0.1.tgz` 后本地安装。Release 同时提供 `.tgz.sha256` 校验文件；具体 SHA-256 以 Release 资产页和校验文件为准。
