# dsh-auto-workflow v1.2.0

兼容 DSH 0.2.2，并更新开发示例的 seed 生命周期。

## 更新

- agent 节点改为按宿主顶层的 `SubagentActivationSpec` 启动（DSH 0.2.2-rc.2 起移除了嵌套 `request`），最低 DSH 版本提升为 `>=0.2.2-rc.2`。
- 修复从看板修改模型时偶发的 409：run 刚 park、调度切片正在收尾时不再被误判为忙碌。
- 开发示例的 seed 改为轮转调度与显式恢复：新增在途水位、`recover-seeds` / `retire-seed` / `rearm-seed`；需求合并或拒绝后，对应方向会重新入队。
- 示例业务 store 升到 `version: 3`，旧版本 dataRoot 不再接受。
- `pr-init` 新增 `manualGate`：使用手动合并门禁的仓库不再被 branch protection 检查挡住。

## 安装

```bash
dsh plugin --profile desktop add github:lyingloong/dsh-auto-workflow#v1.2.0
```
